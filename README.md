# Hi, I'm Alex Druz 👋

**Integration Engineer & QA Lead in iGaming** · Poland (remote)

I connect casino games to operator platforms on the game provider (RGS) side.
Nearly 9 years in software testing and QA, 3.5 of them in iGaming: technical setup, API testing,
troubleshooting, QA sign-off and production releases.

## 🎯 What I do

- **Operator integrations** — 100+ integrations, usually several in parallel, from technical setup to go-live
- **Troubleshooting** — API, wallet, game launch and configuration issues through logs (AWS Loki, Grafana), browser DevTools and Postman
- **QA process** — cut integration testing from ~3 weeks to 3 days by classifying integrations by type and building a test plan for each
- **Team** — led a QA team of 2–3 engineers, mentored a junior QA who grew to senior level, built an onboarding plan (4 weeks instead of 2 months)
- **AI & automation** — led a 6-person team to 2nd place in an internal AI hackathon with my idea: an n8n Slack assistant (RAG) that answers integration questions from approved docs

## 🛠️ What I'm building here

Small, working projects around one idea: **a mock iGaming wallet API and everything you need to test it.**

| Project | What it shows | Status |
|---|---|---|
| `igaming-wallet-mock` | Python mock of a seamless wallet API: auth, bet, win, refund, request signatures, idempotency | 🚧 in progress |
| `api-testing-postman` | Postman collection for the mock, run in CI with Newman | 📋 planned |
| `sql-practice` | iGaming schema and data checks: bets vs balance, duplicate transactions | 📋 planned |
| `playwright-tests` | API and UI tests in TypeScript | 📋 planned |
| `n8n-workflows` | Automation workflows | 📋 planned |
| `ai-qa-tools` | Small AI helpers for QA | 📋 planned |
